# Startup Bharat — Indian Startup Analysis
MS Elevate × AICTE Internship Capstone Project 2026

## Project Title
Startup Bharat: Decoding Success and Failure in the Indian Startup Ecosystem

## Tool Used
Microsoft Power BI Desktop

## Dataset
Simulated Indian Startup Dataset — 3,000 records (2010–2023)

## Key Insights
- 12.10% overall startup success rate
- FoodTech & HRTech have highest survival rates
- Series A funded startups perform best
- Delhi NCR leads in success rate among cities
